## 修复记录（代码审查后落地）

| 问题 | 处理 |
| --- | --- |
| 容器内 `validate` 缺 `jsonschema` | 镜像增加 `py3-jsonschema` |
| 单采样被扣稳定分（总分上限 85） | 单样本按中性 1.0 处理 |
| 评分快照损坏中断整轮 | `_score_table()` 逐条兜底，坏条目跳过并告警 |
| 先落盘后重载 | 改为先 payload 重载、成功后再落盘 |
| geo 资产缺失报错误导 | 前置检查并给出 `run tools/seed_dev.sh` 提示 |
| 新鲜度阈值与契约不一致 | 默认 43200s，compose 显式传参 |
| 归档按 mtime 轮换 | 改为按文件名排序 |
| 容器内本地节点路径缺省 | `MIHOMO_LOCAL_NODES=/data/secrets/local-nodes.yaml` |
| 代码内硬编码站点域名 | 改为 `MIHOMO_SITE_*` 运行期配置 |
| 镜像 tag 外部不可拉 | 默认上游镜像 + `CORE_BIN` 参数化 |
| 首次启动内核先起、配置后生成 | 增加一次性 `init` 服务（落盘后才启动 core），并用 `.config-installed` 标记区分内核 stub |
| 容器内 schema 目录找不到 | `SCHEMAS_DIR` 环境变量 + `./schemas:/opt/schemas:ro` 挂载 |
| 离线开发池无法被 schema 接受 | 订阅池 URL 允许 `file://`（生产仍须 http(s)） |
| `COPY --from` 的 ARG 未在 stage 内声明 | stage 内重新声明 `CORE_BIN`，版本检查去掉管道 |
